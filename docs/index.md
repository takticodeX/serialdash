# SerialDash

A serial monitor and live dashboard for Arduino, ESP32, ESP8266, RP2040 and friends — running entirely in your browser via [Web Serial](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API). No install, works offline after the first visit, and stays fully compatible with plain `Serial.println` sketches.
