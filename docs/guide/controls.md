# Controls

::: info
Controls work end to end as of **M4** (SPEC.md §11): the three P0 control widgets (button, switch, slider) support the full pending/error/disabled state machine and rate limiting from SPEC.md §3.6. This page's own polished walkthrough (with screenshots) is scheduled for **M5** alongside `dashboard.md`. For the protocol semantics in the meantime, see [protocol → controls](../protocol/controls); for the library's `onControl` API, see `lib/SerialDash/README.md` and `examples/04_Controls` in the repository.
:::
